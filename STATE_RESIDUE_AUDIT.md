# State residue audit

Empty hardware surfaces after the texture rebuild. The standard is a continuous field, not a letter-readability threshold.

## BPM empty well

`assets/north-star-v4/parts/bpm-plate-empty.png` (also written as `bpm-plate.png`, which production requires).

Interior luminance mean 10.3, standard deviation 5.3. The well stays a dark textured field. Live BPM ink is a separate layer (`bpm-value.png` / live readout), so 60, 120, 160, 240, and 400 sit on that field.

## Meter empty well

`assets/north-star-v4/parts/meter-shell-empty.png` (production requires `meter-shell.png`, the same empty shell).

Interior luminance mean 12.9, standard deviation 7.5. The inner well is one dark field. Meter ink is `meter-ink.png`, restored on top for 4/4 and swapped by the live meter for 3/4, 6/8, 7/8, and 12/8.

## Nav empty tray

`assets/north-star-v4/parts/nav-tray-empty.png` (production requires this file).

Slot interior means: 6.50, 6.10, 6.22, 6.13, 6.30, 5.91. Standard deviations are about 1.1–1.8. No slot is brighter than the others, so the old icon and label shadows are not a second image under the live slot art.

## Composite

Rebuilding plate, meter, and nav with their live foreground art matches the North Star source at MAE 0 inside those parts. The full 390 instrument MAE is 3.870.
