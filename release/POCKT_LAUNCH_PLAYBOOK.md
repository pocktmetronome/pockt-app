# POCKT Launch Playbook

Do not invent adoption numbers. Do not submit the public App Store release from this document.

## PHASE 0 — TRUST
- Timing validated on device at 20–400 BPM
- Sounds previewed and bundled
- Crash/navigation clean
- TestFlight musicians confirm
- App Store metadata ready in `release/`

## PHASE 1 — SEED
Invite real musicians and teachers. Ask for honest replacement-week feedback, not praise.
Identify 3–5 rooms that cause an “I want this” reaction.
Verify Stage and Practice are actually used.

## PHASE 2 — APP STORE
Generic metronome discoverability.
Screenshot story from the finished app.
Localized metadata after English is stable.
Accessibility labels only when the common tasks meet Apple’s criteria.

## PHASE 3 — CREATOR / TEACHER
Short visual demos.
Teacher recommendation kit.
No paid fake reviews.
No review manipulation.

## PHASE 4 — BANDS / STAGE
Show setlist workflow in rehearsal.
Emphasize free / no ads / no subscription.
Show one-tap song creation from the current metronome state.

## PHASE 5 — ITERATE
Use App Store Connect / App Analytics for impressions, product page views, conversion, downloads, retention, crashes, ratings.
Use TestFlight interviews for room and feature understanding.
Never claim usage numbers that do not exist.
